## 达标判定

以下阈值首次同时满足全部门槛：0.60、0.65。接入默认链路仍需按 PRD 第 4 节完成 includeSemanticCandidates 开关实现、回滚验证与人工评估；本报告只回答指标问题。

## 解释与边界

本扫描只改变语义文档级候选分数下限一个变量，所有阈值复用同一次真实向量化结果，不产生额外 Embedding 请求，也不修改任何默认候选链路。内容臂与阈值无关。结论仅适用于当次端点、模型、版本和 v2 固定资料集；更换任一变量后必须重新扫描。本结果不代表大规模 ANN 性能、真实模型并发或生产部署质量。
