## 达标判定

接入门槛取自 PRD 第 4 节：融合臂 Recall@8 不低于内容臂（1.0000）、Precision@8 不低于 0.1707、硬负例为 0 且孤立文档语义候选为 0。

扫描范围内没有任何阈值同时满足全部门槛条件；语义候选继续不接入默认链路。

## 解释与边界

本扫描只改变语义文档级候选分数下限一个变量，所有阈值复用同一次真实向量化结果，不产生额外 Embedding 请求，也不修改任何默认候选链路。内容臂与阈值无关，其基线为 Recall@8=1.0000、Precision@8=0.1707。结论仅适用于当次端点、模型、版本和 12 份固定资料集；更换任一变量后必须重新扫描。本结果不代表大规模 ANN 性能、真实模型并发或生产部署质量。
